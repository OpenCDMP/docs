## Statistics Scope Selection

The Statistics page supports role-based scope selection, allowing eligible users to switch between different views of the data depending on their administrative privileges.

Two statistics scopes are available:

- **Tenant Scope**: Displays statistics only for the tenant you are currently logged in to. All charts reflect data that belongs exclusively to the selected tenant.

- **Multitenant Scope**: Displays statistics across all tenants. When selected, charts combine data from all tenants where you hold administrative access, providing a global overview of system usage and growth.

:::note
- Charts are generated by [KPI service](optional-services/kpi.md)
- Chart data is filtered based by tenant you are logged in with.
:::

:::info
This page is available if [KPI service](optional-services/kpi.md) is enabled
:::

:::warning
To display data to charts you **must** create an Indicator. More details can be found in [maintenance indicator events](admin-guide/maintenance.md#indicator-events)
:::

## Authorization

Only users that have any type of **Global Admin** roles or **Tenant Specific Admin** roles can access this page.

:::warning
Only the users who have access to charts can view the data. More details can be found in [maintenance indicator events](admin-guide/maintenance.md#indicator-events)
:::

## Navigation

This view is available when the user presses the `Statistics` link from the side navigation menu.
